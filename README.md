# 六点盲文转写校对台（英语盲文教学子集）

一个纯浏览器内运行的英文盲文转写 / 校对工具：打开即是**源文与点字并排的编辑区**，
所有资料（正文、批注、逐词禁用设置）只保存在本机浏览器 `localStorage`，刷新自动恢复，
不经过任何服务器。

面向无障碍出版的**校对场景**：随时知道某个点字是原文哪个词/字母来的、为什么可以这样缩写。

## 运行方式

需要 Node.js 18+。

```bash
npm install
npm run dev        # 开发服务器（终端会打印 http://localhost:5173 地址）
```

其他命令：

```bash
npm test           # 运行 vitest 单元测试（模式切换 / 映射 / 批注定位等，共 33 个）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建
```

## 功能

- **并排校对**：左侧源文可直接编辑，右侧点字实时重新转写。
- **双向定位**：
  - 点击任一点字 → 反选其来源文字（一个词缩写成一个点字时选中整个词；一个大写字母/数字
    需要多个点字时，选中该字母会同时高亮大写前缀/数字前缀与字形点字）；
  - 在源文中拖选 → 高亮对应的全部点字，状态栏显示对应点数。
- **逐词禁用缩写**：选中一个缩写词可把它按字母展开校对，随时重新启用；设置随编辑重定位。
- **批注**：对任意选区添加批注；编辑前文后批注跟随原词移动，不会漂到别的词；
  同名片段不唯一时**保留原位并明确提示**，原词被删除时报“无法继续对应”。
- **撤销 / 重做**：工具栏按钮或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（`Ctrl+Y`），连续打字合并为一个检查点。
- **刷新恢复**：文档与批注自动保存在 `localStorage`；“恢复示例段落”可一键还原内置样例。
- **规则可查**：顶部“📖 规则与适用范围”列出全部点位与缩写理由；悬停任一点字也有解释。
- **未支持字符不丢失**：用红色 `⿽` 标出、角标显示原字符，并计入状态栏统计。

内置示例段落同时包含：五个整词缩写、年份 `2024` / `1829`（数字模式）、全大写 `THE`、
首字母大写 `The` / `Anna`，以及 `Sandy`、`office`、`forum` 这类**词内含假缩写**的词。

## 教学子集范围与限制

本工具只实现题目明确列出的子集，**不是完整英语盲文（EBAE/UEB）**：

| 类别 | 内容 |
| --- | --- |
| 字母 | a–z 标准点位 |
| 大小写 | 大写前缀 ⠠（点 6）：单大写一个 ⠠，整词全大写两个 ⠠ |
| 数字 | 数字前缀 ⠼（点 3456）+ a–j 复用为 1–0；遇非数字字符立即退出模式，再次出现数字重新加前缀 |
| 标点 | `. , ? ! ; : ' - / " “ ” ( )` |
| 整词缩写 | `and ⠯`、`for ⠿`、`of ⠷`、`the ⠹`、`with ⠾`，**仅整词边界命中**（前后不能是字母/数字） |

明确**不支持**（遇到会标红提示而非静默处理或错误转写）：

- 其它任何缩写（字母组词如 `ing/ed`、部分词缩写如 `ch/sh/th`、下缀等）；
- 货币符号、数学/化学符号、重音字母、非拉丁文字、Emoji；
- 复合排版规则（如大写段落标记、分行连字、专用引号/括号配对符）。

两点约定（子集内简化，规则弹窗中也有说明）：

- 左右括号都作 ⠶（2356），靠位置区分；
- 左双引号 ⠦ 与问号同形，靠上下文区分；直引号 `"` 按相邻字符自动判左右。

## 代码结构

```
src/
  braille/
    rules.ts       点位与规则表（字母/标点/五个缩写）
    transcribe.ts  转写引擎：源文 -> 带源码区间的点字序列；双向映射
    anchors.ts     批注/禁用锚点重定位（fresh/moved/ambiguous/broken）
    sample.ts      内置示例段落
    *.test.ts      vitest 测试
  components/
    BraillePane.tsx 点字面板（点击/高亮/标记）
    RulesModal.tsx  规则与适用范围
  state.ts         useReducer：编辑、撤销重做、锚点重定位、持久化
  App.tsx          并排校对台主界面
```

### 实现要点

- 每个点字单元都带 `srcStart/srcEnd`：普通字符映射到自身区间；**前缀点字（⠠/⠼）为零宽度，
  锚定在它修饰的字符上**，因此“一个字母 → 多个点字”“一个词 → 一个点字”都能精确互选。
- 缩写判定只有一处（`matchContraction`）：先按字母取词、再要求前后均非词字符，
  转写引擎和界面共用，杜绝词内误吞。
- 批注保存原文片段 + 偏移；编辑后按“原地 → 唯一最近精确匹配 → 忽略空白/大小写匹配”的顺序
  重定位，歧义或丢失时显式报告，不猜测、不乱挂。
