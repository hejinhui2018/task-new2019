# 英文六点盲文转写校对台（教学子集）

面向无障碍出版编辑校对场景的**浏览器内**英文盲文转写与校对工具。打开即是
**源文与点字并排**的编辑区：左侧可直接编辑原文，右侧实时给出六点点字；
每个点字都记录了它来自原文的哪个字符区间，支持双向定位、逐词禁用缩写、
按词挂批注，且数据全部保存在浏览器本地（localStorage）。

技术栈：**React 18 + TypeScript + Vite**，测试用 **Vitest + Testing Library**。

## 运行方式

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm test           # 运行全部测试（47 个，含模式切换/映射/批注定位/持久化）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建
```

无需后端、无需账号；所有内容只存在当前浏览器的 localStorage
（键名 `braille-proofing-console/v1`），刷新页面自动恢复。

## 功能

### 转写（教学子集）

- **字母**：A–Z 标准六点字母表。
- **大小写**：
  - 大写号 ⠠（6 点）置于单个大写字母前；
  - 全大写词号 ⠠⠠（6-6）置于长度 ≥2 的全大写单词前，词内逐字母拼写。
- **数字模式**：数字号 ⠼（3-4-5-6 点）后借 a–j 点位表示 1–9、0；
  数字串结束（空格、标点、字母）即退出数字模式，下一串数字重新发数字号。
- **常用标点**：逗号、分号、冒号、句号、叹号、问号、撇号、连字符、
  左右括号、斜线、双引号（教学子集开闭统一为 2-3-6）。
- **5 个完整词缩写**：`and` ⠏、`for` ⠟、`of` ⠗、`the` ⠞、`with` ⠺。
  - **只命中完整单词**：分词以连续字母串为词，因此 `forest` 不会缩写 `for`、
    `theater` 不会缩写 `the`、`sand` 不会缩写 `and`、`without` 不会缩写 `with`。
  - 标点是词边界，所以 `the.` 中的 `the` 仍可缩写。
- **未支持字符不丢弃**：子集外字符（如 `#`、`@`、中文等）会在两侧编辑区
  以醒目的红色虚框标出，右侧标题与底部状态栏给出计数。

### 校对

- **双向定位**：
  - 点击任意点字（含大写号、数字号等前缀）→ 左侧原文对应区间被选中并滚动到可见处；
  - 在左侧拖选原文 → 覆盖该区间的所有点字高亮（一个字母对应多个点字时，
    如大写 `A` = 大写号+字母点字，两个点字同时高亮）。
  - 一个词缩写成一个点字时，该点字覆盖整词区间，定位准确。
- **逐词禁用缩写**：校对面板中可对某个缩写词临时禁用，右侧立即恢复逐字母拼写；
  可再次勾选恢复。禁用状态按词的身份保存。
- **批注不漂移**：批注挂在 token 的**稳定身份**上。编辑原文后做有序对齐
  （公共同前缀/后缀 + 编辑区内保序加权匹配，单词内插删一个字符按同一词跟随），
  因此在词中间打字、在段首插入句子，批注都留在原词上，不会漂到后面的同形词。
- **无法对应时明确提示**：如果被批注（或被禁用缩写）的词在新文本中找不到对应，
  顶部出现警告条逐条列出该词与其批注/禁用状态——绝不静默丢弃；撤销可恢复。
- **撤销 / 重做**：工具栏按钮或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（亦支持 `Ctrl+Y`）。
- **规则查看**：右上角“规则与适用范围”弹窗列出全部点位表、适用边界与子集限制。
- **内置示例**：首次打开载入一段含缩写词、四位年份 `2024` 与全大写词 `BBC` 的短段落
  （同时故意包含 `theater`、`sand` 等用于验证“不吞词内字符”的词）；
  可随时点“载入示例”重置。

## 教学子集限制（重要）

这是**教学子集**，不是完整 EBAE/UEB 转写器：

- 只有 5 个**完整词**缩写；没有字母组合缩写（tion、ed、ing 等）、
  短词形式词（en/in 等）与强/弱缩写。
- 数字采用“每串数字前发数字号、串结束即退出”的简化规则；
  不处理数字内逗号/小数点连读、序数词、数字与字母连写。
- 双引号不区分开闭；不支持着重号、换页/续行连字符等排版规则。
- 空白按词间空方处理，不做按行宽的折行排版算法。

## 目录结构

```
src/
  braille/
    dots.ts        # 六点点位表、字母/数字/标点/缩写/前缀号
    tokenize.ts    # 原文分词（word/number/space/punct/unsupported）
    transcribe.ts  # 分词 → 带源码区间的盲符序列（模式切换、缩写）
    align.ts       # 编辑后 token 身份对齐（批注防漂移、orphan 检测）
    rules.ts       # 规则面板的权威说明数据
    sample.ts      # 内置示例段落
  state/
    document.ts    # reducer：编辑/批注/禁用/撤销重做/序列化
  components/      # DotCell / BraillePanel / SourceEditor / ProofingPanel / …
  __tests__/       # 引擎、对齐、状态与应用级测试
```

## 设计要点

- 每个输出盲符都带 `[start, end)` 源码区间；前缀号（大写号/数字号）区间与其
  修饰对象一致，因此“点前缀号也能反查到字母/数字”。
- 批注与禁用只存 token id；每次编辑后重新对齐身份，几何区间永远由当前原文重算，
  避免存储陈旧偏移。
- 核心逻辑（分词、转写、对齐、reducer、序列化）均为纯函数，可直接单测。
